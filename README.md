# undersea_fiber_optic_sensing_and_noise

This page contains four sections of code.
  1. The "environmental-models" section contains codes for analyzing signal recovery from 3 different types of environmental disturbances and 4 different types of interrogation signals.
  2. The "fiber_simulation" code provides a simulation ("ofdr_phase_recovery_frontend.ipynb") for recovery of fiber disturbances at specific locations along the cable.
  3. The "whalesong_spacetime_combined" folder includes and audio file for a whale song (whalesong.wav) and a simulation ("whalesong_spacetime_combined.ipynb" for recovering the whale song from temporal data of the cable.
  4. The final code ("OFDR Signal recovery (with physical noise).ipynb") simulates the recovery of signals from cable disturbances when noise is added to the laser. Our model for laser noise comes from "Semiclassical theory of noise in semiconductor lasers - Part II" by  Kerry Vahala and Amnon Yariv.
